and optional character features for NB/SVM. No paid services or automatic relabeling.

- [ ] Reproduce ambiguous abbreviation errors with temporary regression checks.

- [ ] Add optional train-only character features alongside word BoW/TF-IDF,

Character features use 3–5 character ngrams within words. Each branch receives
the configured vocabulary limit; combined matrices may have twice that limit.
This adds robustness without claiming semantic understanding or higher accuracy.
